## 한 신청 건을 처리하는 방법

1. 본사에서 신청번호를 부여하고 전 문서에 같은 번호를 기록합니다. 파일명 권장: `신청번호_문서종류_작성일`.
2. 신청서의 본사 배포 준비란(개인정보 수집주체의 법적 명칭·보유기간·문의처·접수처)을 채운 뒤 신청인에게 제공합니다. 현재 미정 값을 임의로 넣지 않았습니다.
3. 신청서 접수 후 인터뷰 일정을 지정합니다. 평가기준과 제안 판정 구간은 본사 승인 후 동일 기수에 동일하게 적용합니다.
4. 평가표 2쪽에서 각 항목 0~5점을 고르면 합계가 계산됩니다. 10개 모두 평가하기 전에는 합계를 확정하지 않습니다. 미평가는 0점과 다릅니다.
5. Audit에서 보유 사실과 적합성 판단을 분리하고 증빙·판정자·보완 기한을 기록합니다. A/B/C는 장비 준비 상태이며 선정 등급이 아닙니다.
6. 평가표 3쪽에서 지역 현황·잔여 Hub 수·권역 중복·결정 근거를 기록한 후 최종 승인과 통지를 남깁니다. 조건부 선정은 해소 조건과 확인 담당자를 지정합니다.
7. Term Sheet에 실제 적용 단가·지역 조건·계약기간·VAT·해지·환불 등 합의 내용을 적고, 미결 조건은 담당자·기한을 지정합니다. 정식 계약으로 이관할 내용을 기록하는 협의용 초안입니다.

## 작성과 저장

- 입력란을 클릭해 작성합니다. 체크·단일 선택과 점수 선택을 사용할 수 있습니다.
- 자동 저장, 서버 전송, 브라우저 영구저장은 하지 않습니다. 종료 전 **작성내용 저장(JSON)** 버튼을 누르세요.
- 같은 문서의 **불러오기**로 JSON을 복원할 수 있습니다. 다른 문서 파일은 거부합니다.
- 작성본을 공유할 때 **인쇄 / PDF 저장**으로 PDF를 만드세요. 기본 제공 PDF는 빈 양식입니다.
- 인쇄 버튼은 본문이 하단 페이지 번호와 겹치는지 확인합니다. 긴 답변은 요약하고 신청번호가 표시된 별첨으로 관리하세요. 브라우저 자체 인쇄 메뉴는 이 검사 없이 실행될 수 있습니다.
- 내용 입력란은 실무 기록용이며 전자서명 인증 기능이 아닙니다.
- 원장별 저장 파일에는 신청정보가 포함됩니다. 지정된 담당자만 접근 가능한 위치에서 관리하며 환자 식별자료를 수집하지 않습니다.
- HTML을 개별 파일만 옮기지 말고 폴더 구조를 유지하세요. 폰트는 기존 브로셔의 로컬 자산을 참조합니다.

## 확정 조건과 새로 제안한 항목

확정 사업조건: 2026-09-26 사용자 결정 및 `../mps-founding-brochure/README.md` 기준.

- BWA 2.0S 3,300만원 / 근골격계 초음파 최소 2,000만원 / KINVENT 4종 2,275만원.
- 인증비 100만원 / 월 49만원 및 기존 포함항목 유지 / 건별 검사비 별도.
- 기본장비 신규 기준 약 5,417만원부터. 가격 합계는 최소·시작금액을 적용한 기준이지 공급사 최종 견적서가 아닙니다.
- Hub: 서울 추가 3곳 / 경기 북부·서부·동부 수량 별도 협의 / 그 외 광역시·도청 소재지 각 1곳.
- 현재 Founding 10은 서울·경기. 타 지역 Hub 정책과 이번 기수 모집 범위를 분리합니다.

새로 제안한 운영 기준: 10개 평가항목 각 5점, 40점 이상 우선 검토·30점 이상 보완 검토·30점 미만 보류 검토. **승인된 정책이 아니라 운영안**입니다. 문서에도 동일하게 표시했습니다. 최종 선정은 점수와 별도로 장비·지역·승인 근거를 기록합니다.

미정 조건: 개인정보 수집주체·보유기간·문의처·제출처, 계약기간·갱신·VAT·과금시점·건별 확정단가·환불·해지·독점 여부·권역 경계·지원 상세 범위·정보 처리 역할. 선택형 한약·뉴트리션 공급조건도 미정입니다.
