# MPS 인증센터 · 축구레슨장 사업 실행자료 v1.0

`index.html`이 시작 화면입니다. 이전 한의원용 실행자료와 별도 폴더로 제작했습니다.

## 사업 모델

- **레슨센터:** 축구레슨을 제공하는 MPS 인증센터. 소속 선수의 측정 결과를 참고해 코치별 훈련·관리를 수행하고 MPS에 월 프로그램·대시보드 구독료를 납부합니다.
- **측정센터:** 인근 한의원. 선수 측정·결과 작성·공유 승인 범위 내 전달을 담당합니다.
- **MPS:** 프로그램·대시보드 제공과 운영 연계. 실제 기능·지원 범위와 출시일은 계약 시 확정합니다.

한의원용 100만원 인증비·월 49만원·필수장비 구매·Regional Hub 정원을 레슨센터에 적용하지 않았습니다. 월 구독 금액과 선수 수 기준은 미정입니다.

## 측정비 두 결제안

| 항목 | A안 | B안 |
| --- | --- | --- |
| 결제 | 선수·보호자가 측정센터에 개별 결제 | 여러 선수 측정비를 합산해 측정센터에 일괄결제 |
| 수납 관리 | 개인별 결제 상태와 증빙 | 통합 청구번호·선수별 배분 명세 |
| 확정할 담당 | 측정센터 수납·환불 담당 | 일괄 결제자·보호자 수납 담당·증빙 주체 |
| 취소·환불 | 개인 결제 건별 처리 | 명단 변경·개별 조정·환불 수령자 확인 |

B안은 사용자가 승인한 해석대로 **측정센터에 합산 결제하는 방식**입니다. 일괄 결제자는 임의로 레슨센터로 고정하지 않았습니다. 보호자에게 따로 수납하지 않는 경우도 해당 칸에 기록할 수 있습니다. 실제 결제 전 담당과 증빙·환불 조건을 지정합니다. A/B 혼합 운영은 제안 선택란으로 제공하며 측정센터와 사전 합의합니다.

## 실제 운영 절차

신청 → 대표·코치 인터뷰 → 운영·측정 연계 점검 → 지역·연계 검토 → 최종 선정 → 계약 → 온보딩 → Launch.

1. 같은 센터번호를 5종 양식에 사용합니다. 선수별 실제 운영 카드는 센터번호와 선수 관리 ID로 연결합니다.
2. 신청서의 개인정보 수집주체·보유기간·문의처·접수처를 본사가 확정·기입한 뒤 배포합니다. 모집 신청 단계에는 선수 건강자료를 수집하지 않습니다.
3. 10항목×5점 및 40/30점 구간은 본사 운영 **제안안**입니다. 승인 후 적용합니다. 미평가를 0점 처리하지 않으며 점수만으로 선정하지 않습니다.
4. 운영 점검에서 담당 코치·측정센터 연락체계·공유 승인 확인·계정·관리 기록 준비를 확인합니다.
5. 평가표 3쪽에서 지역 연계 가능성과 승인·조건·통지 기록을 남깁니다. 지역 독점·선정 수량은 미정입니다.
6. Term Sheet에서 구독 금액·과금 기준과 A/B 측정비의 담당·금액·취소·환불을 별도로 합의합니다.
7. 실제 운영 전 필요한 선수·보호자 정보 처리 및 결과 공유 절차를 확정합니다. 대표자의 모집 신청 동의와 선수정보 공유 승인은 다른 절차입니다.

## 작성·저장·인쇄

- HTML에서 입력 후 **작성내용 저장(JSON)**을 누릅니다. 자동 저장·서버 전송은 없습니다.
- **불러오기**로 같은 레슨센터용 문서의 JSON을 복원합니다. 한의원용 저장 파일과 섞이지 않도록 문서군을 검사합니다.
- **인쇄 / PDF 저장**은 본문이 페이지 번호 영역을 침범하는지 확인합니다. 긴 내용은 별첨에 적습니다. 브라우저 자체 인쇄는 이 검사를 우회할 수 있습니다.
- 점수는 자동 합산됩니다. Audit 금액표는 수기 대조용이며 합계 자동 계산은 없습니다.
- 서명란은 기록용이며 전자서명 인증 기능은 아닙니다.
- 실제 작성본에는 개인정보가 포함될 수 있습니다. 지정된 담당자가 접근 가능한 저장 위치를 사용합니다.
- HTML은 로컬 브로셔 폰트를 참조하므로 현재 폴더 구조를 유지하세요.

## 문서 상태·근거

사용자 확정: 축구레슨장 인증센터 모델, 한의원 측정·결과 연계, 대시보드 제공, 월 결제·구독료, A/B 두 측정비 결제안.

운영 제안: 50점 세부 기준·구간, 선수별 관리 카드, 대시보드 상세 기능·역할별 권한, A/B 혼합 운영 기록 구조. 모두 실제 정책·제공 기능 확정 전에 확인해야 합니다.

미정: 구독 방식·금액·인원 기준·과금시점·가입비 유무, 측정 항목·단가·주기, B안 실제 결제자·보호자 수납 담당, 취소·환불·증빙, 개인정보 처리 주체·보유기간·공유 구조, 지역 권리, 계약기간·종료조건.

정보 처리 문서 검토 시 참고할 공식 자료: [개인정보 보호법 제17조](https://www.law.go.kr/법령/개인정보보호법/제17조), [제23조](https://www.law.go.kr/법령/개인정보보호법/제23조), [제22조의2](https://www.law.go.kr/법령/개인정보보호법/제22조의2). 이 자료 세트의 신청서는 센터 대표자의 모집 신청용이며 선수 건강정보 공유 동의서가 아닙니다.

Term Sheet는 협의용 초안이며 정식 계약서·완결된 법률 검토를 대신하지 않습니다. 대시보드는 기능 제안용 데모이며 운영 서비스가 아닙니다.
