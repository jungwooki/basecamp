운영·측정 연계 점검표장비 Audit를 대신하는 운영 준비 점검

MPS 인증센터 = 축구레슨장
레슨센터 선수 등록 → 인근 측정센터(한의원)에서 측정 → 공유 승인된 결과 확인 → 코치별 맞춤 관리 → 다음 측정·관리 점검. 장비 구매보다 프로그램·대시보드 월 구독을 중심으로 운영합니다.

02. 운영 판정

별도 측정장비 구매를 가입 전제로 삼지 않습니다. 본 점검은 축구레슨 운영과 연계 준비도를 확인하며 한의원의 장비 Audit를 대신하지 않습니다.

03. 선수별 측정 연계·관리 카드

실제 운영 시 선수 1명·측정 1회 기준으로 복제합니다. 선수 식별은 관리 ID를 우선 사용하고 공유 승인된 정보만 기록합니다.

단계기록 / 담당 / 확인일

측정 완료 / 결과 수신측정일·결과 버전·작성 기관

보호자 설명 / 확인설명일·질문·후속 안내 담당
재점검다음 관리 점검일·재측정 협의일·담당

04. 월간 선수 관리 점검

측정 결과·전문가 의견과 코치의 훈련 기록은 별도 항목으로 보존합니다. 코치가 측정 원본을 수정하지 않으며 추가 판단이 필요한 내용은 측정센터에 문의합니다.

05. 측정비 결제·정산 기록

구분A안 · 선수·보호자 직접 결제B안 · 측정센터 일괄결제
결제선수·보호자가 측정센터에 개별 결제여러 선수 측정비를 합산하여 측정센터에 1회 결제
관리개인별 예약·결제·취소 확인확정 명단·통합 청구·개별 배분·환불 확인
담당측정센터의 수납 담당 지정일괄 결제자와 보호자 수납 담당 별도 지정
선수 ID / A·B측정비조정·환불액최종 청구액결제 상태 / 증빙

최종 청구액 = 측정비 + 추가 청구액 - 할인·환불액. 조정란에는 부호와 사유를 기입합니다. A안은 선수별 결제 확인용, B안은 동일 통합청구 번호에 속한 선수별 배분표입니다.

06. MPS 월 구독료 확인 (측정비와 별도)

금액란은 수기 대조용이며 자동 계산하지 않습니다. 한 선수·한 측정 회차에 A/B 중 하나를 적용하여 중복 청구하지 않습니다. 측정비를 MPS 월 구독료에 합산하거나 소개 수수료로 간주하지 않습니다.
