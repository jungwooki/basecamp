# MPS Basecamp · 본부 워크스페이스

시작: `index.html` (현재 Live Server 예: http://127.0.0.1:5501/mps_basecamp/index.html)
기존 admin 계정과 요청한 초기 비밀번호를 유지합니다.

## 페이지
- `index.html`: 종합 관리 → 소개 브로셔 → 모바일·스탠다드·심화 리포트 → 넥스트로컬 → 회사 노션
- `athletes.html`: 선수·팀 콘솔, 팀 대시보드 활성 상태, 지도, 지도자 설명 가이드
- `clinic.html`: 제휴의료기관 콘솔, 홈페이지, 서베이, EMR, Growth AI 소개, 현장·의료진 매뉴얼, 서식
- `center.html`: 스킬·피지컬·종합센터, 운영 서식과 바이오밴딩 자료실
- `player.html?id=...`: 선수 프로그램, 복수 소속기관, 선수별 리포트 링크, 메모
- `organization.html?id=...`: 기관 유형, 운영 상태, 대시보드, 소속 선수
- `guide.html?kind=...&page=...`: 실제 이미지/업무 흐름 왼쪽, 읽는 순서·용어·설명 예시 오른쪽
- `nextlocal.html`: @nextlocal 원본의 2026년 9월 진행상황을 요약한 프로젝트 페이지

## 설명 가이드
`guides.js`에서 내용을 관리합니다. 총 47개 화면/단계입니다.
- 모바일 4탭, 스탠다드 12페이지: 지정한 sportsmps.com 공개 샘플 캡처
- 멘탈 4 / 피지컬 4 / 성장체질 5: 기존 심화 샘플 PDF에 대응하는 이미지
- 팀 대시보드 5화면: 요약, 피지컬, 성장, 멘탈, 선수 상세
- 클리닉 5 / 센터 4 / 멘탈 프로그램 4단계: 기존 자료를 바탕으로 구성한 업무 설명 (실제 콘솔 캡처 아님)

`assets/guides/`의 온라인 화면은 2026-09-27 캡처입니다. 실시간 화면이 아닙니다. 원본 열기 버튼으로 최신 서비스를 엽니다.
샘플 숫자는 실제 운영 실적이 아닙니다. 내부 지수와 임시 기준은 진단이나 부상 확률로 설명하지 않습니다. 일부 모바일/심화 지표의 방향 차이 및 원본의 모호한 나이 표기를 가이드에 명시했습니다.

## 저장과 데이터 이전
- `data.js`: 기관 유형, 리포트 필드, 첫 실행 가상 샘플
- `app.js`: 로그인 화면, 선수/기관 관리, 상세보기, 가이드 표시
- 저장 키: `mps-basecamp-data-v2` (localStorage)
- 기존 `mps-basecamp-orgs-v1` 자료가 있으면 그대로 이전합니다. 실제 선수를 임의로 생성하지 않도록 이전 시 선수 목록은 비워 둡니다.
- 같은 브라우저·같은 주소의 창 사이에서 변경을 반영합니다. 다른 기기/다른 포트와 자동 동기화하지 않습니다.
- 백업 내보내기/가져오기 제공. 가져오기는 ID 중복, 기관 참조, 유형, 상태, 링크 형식을 검사하며 현재 목록 교체 전 확인합니다.
- 기관 삭제 시 선수 소속 연결만 해제하며 선수와 원본 리포트는 삭제하지 않습니다.
- 저장 오류 시 기존 데이터를 덮어쓰지 않고 화면 안내를 표시합니다.

현재 실제 SportsMPS 데이터 API는 연결하지 않았습니다. 숫자는 현재 브라우저 등록 자료의 합계이며, 활성 선수는 관리자가 활성 체크한 선수입니다. 대시보드 활성 역시 관리 입력값이며 외부 계정 권한/접속 상태를 자동 검증하지 않습니다.

## 로그인과 운영 범위
현재 로그인은 로컬 시제품용 JavaScript 화면 제어입니다. 기존 탭 로그인과 호환되며 새 창 상세보기를 위해 브라우저에 로그인 표시를 공유합니다. 로그아웃은 같은 브라우저의 열린 창에 반영합니다.
서버 인증, 구성원별 계정/권한, 동시 편집, 감사 기록, 서버 데이터베이스는 구현되지 않았습니다. 연결된 외부 서비스의 로그인은 각각 독립적입니다. 실제 구성원 공동 운영에는 이러한 연동이 필요합니다.

## 이름 변경 스탠다드 이미지
`reports/standard/`에 기존 요청의 12페이지 PNG와 ZIP, 이미지 뷰어를 유지했습니다. 선수 이름 5곳만 ‘샘플’로 교체했고 원본 PDF는 변경하지 않았습니다. 이름 이외 영역은 원본 대비 픽셀 비교로 확인했습니다. 학교·생년월일·검사 수치 등은 요청대로 원본 그대로이므로 완전 익명화본은 아닙니다.

## 자료 연결
연결 자료와 자산은 resources/ 안에 복사되어 있습니다. mps_basecamp 폴더만 배포하면 내부 자료가 열립니다.
- 인증의료기관: 기존 모집 브로셔/실행 양식 연결. MPS광역클리닉·MPS인증클리닉은 관리 유형이며 새 계약 조건을 임의로 만들지 않았습니다.
- 인증센터: 스킬/피지컬 제휴 제안서. 종합센터 전용 계약 자료가 없어 공통 운영 자료로 표시했습니다.
- 정신건강 진료와 스포츠 멘탈 코칭을 구분하며, `mentalguide/index.html`을 본부 멘탈코치 원본 가이드로 연결했습니다.
- Growth AI는 소개 페이지를 연결하며 평가 기능은 @growthai 문서에 따른 서버 설정이 필요합니다.

## 확인한 동작 (2026-09-27)
로그인 오류/성공, 기관 등록과 대시보드 주소 검증, 선수 등록·복수 소속·활성 상태·리포트 수정, 새 창 상세보기, 창 사이 변경 반영·로그아웃, 삭제, 가이드 앞/뒤·페이지 선택, 모바일 390px 화면과 각 페이지의 이미지 로딩을 확인했습니다. 기존 v1 기관 이전, 손상된 저장값 보호, 중복 ID·잘못된 참조·위험한 URL 가져오기 거부도 검사했습니다. 연결된 로컬 페이지/자산 93개가 HTTP 200으로 응답했습니다. 외부 서비스 권한이나 실제 업무 데이터 연동을 검증한 것은 아닙니다.


## 독립 배포 패키지 (2026-09-28)
- `resources/`: 연결된 브로셔, 리포트, 멘탈 양식, 코치 가이드, 다이어리, 지도, 매뉴얼과 해당 자산. 원본 폴더는 수정하지 않았습니다.
- GitHub에는 이 폴더의 전체 내용을 업로드합니다. `.nojekyll`도 포함합니다. 저장소 하위 경로에서도 상대 링크가 작동합니다.
- `python3 -m http.server 5518 --directory mps_basecamp` (상위 작업폴더에서 실행) 후 `http://localhost:5518/`로 확인합니다.
- `python3 mps_basecamp/scripts/check_links.py`로 정적 HTML/CSS 내부 경로를 검사합니다.
- 이전 브라우저에 저장된 선수 리포트의 상위폴더 경로는 알려진 자료 경로에 한해 자동 변환합니다.
- 기존 2026mental 폴더가 없어, 멘탈 리포트는 2026mental2의 이름에 ‘샘플’이 명시된 리포트를 사용합니다.
- 기존에 없던 일부 팀 로고는 다른 팀 로고로 대체하지 않고 TEAM 기본 배지를 표시합니다.
- SportsMPS·Notion 등 외부 서비스, 지도 타일 및 CDN 라이브러리는 인터넷이 필요합니다.
- GitHub Pages 같은 정적 호스팅은 Growth AI의 `/api/auth/login`·평가 서버를 실행하지 않습니다. EMR의 원격 저장도 기존 외부 서버/권한에 의존합니다. HTML 자료의 독립 배포와 서버 기능은 별개입니다.
- GitHub 업로드/커밋/배포는 이번 파일 정리 작업에서 실행하지 않았습니다.
